=== BUGS (in priority order) ===
[ ] A failed addScore leaves the modal and backdrop stuck open.
    handleSubmit is `await addScore(...)` then `dialogRef.current?.close()`.
    addScore THROWS on "Chart not found" / bad score range, so close() never
    runs. No error is shown either — the user just sees a frozen backdrop.
    Easiest repro: on /scores, hit Add Score without picking a chart.
    ChartSearch sends value='' -> Number('') -> 0 -> lookup fails -> throw.
    Fix: return { error } from the action instead of throwing, show it, and
    only close on success. Also require a chart to be selected.

[ ] Every modal is a different size.
    Modal sets no width, so <dialog> keeps the UA default width: fit-content
    and shrink-wraps its content. The `w-full max-w-5xl` on the children is
    inert — w-full is 100% of a parent that's sized FROM those children.
    Fix: put a real width on the <dialog> in Modal.tsx.
    Also: ScoreModal/BrowseModal pass 2 children to a non-flex dialog, so the
    Add Score button lands in its own full-width block below the card.

[ ] Proxy never refreshes the session.
    utils/supabase/middleware.ts creates the supabase client but never calls
    `await supabase.auth.getUser()`, so the setAll cookie callback never fires
    and tokens never roll over. ESLint flags the client as unused — that IS
    the bug. Fix: make createClient async, call getUser() before returning.

[ ] getPmRating prints the wrong distance.
    Returns `MAX - ${shiny}` but should be `MAX - ${noteCount - shiny}`.
    One note off max on a 1000-note chart currently shows "MAX - 999".
    Now user-visible: ScoreInfo displays it.

[ ] revalidatePath('/') is stale in addScore and ImportFromBrowser.
    The score grid lives at /scores now, so adding a score doesn't refresh it.

[ ] ImportFromBrowser duplicates on re-run.
    Guest rows aren't cleared or flagged, so a second click doubles everything.

[ ] filterCharts: unknown levels leak through < and <= filters.
    A level not in levelOrder gives indexOf -> -1, which passes those comparisons.

[ ] /auth/auth-code-error is an empty anonymous default export.
    This is the repo's only ESLint error (react/display-name).

[] import scores can import duplicate scores
    we need score handling

[] style: importing scores adds success text, which messes up the flex container so add button is bigger
